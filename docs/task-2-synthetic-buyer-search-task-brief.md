# Claude task brief: synthetic web buyer search

Implement or maintain the bounded local synthetic buyer-search experience in
`apps/web`. Use the approved organic visual system and the [web application
direction](web-app-and-pwa-direction.md).

No native package, native build, store distribution, Firebase/GCP service,
Worker binding, database, auth, network request, browser storage, analytics,
real data, prescription, reservation, payment or delivery capability is in
scope.

Required evidence is the full repository quality suite plus web component,
accessibility, manifest and boundary tests. Report responsive browser checks
without claiming device or hosted results that were not run.

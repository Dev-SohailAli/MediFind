## Queue rules

- Read the [stewardship roadmap](../../superpowers/plans/2026-08-18-governance-and-stewardship-roadmap.md), selected brief and linked policies.
- Confirm Tasks 30-37 are accepted or explicitly closed before execution.
- Name a human owner and review cadence; stop if either is missing.
- Keep synthetic rehearsals separate from protected or hosted evidence.
- Do not place credentials, real data, private legal/support correspondence or
  raw prescription content in source, issues, PRs, logs or exports.
- Do not merge, deploy, publish, sign, grant access or release without the
  recorded founder/release-owner decision.

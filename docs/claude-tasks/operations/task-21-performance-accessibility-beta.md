# Task 21: Verify performance, accessibility, language and beta acceptance

## Gate

Requires stable protected flows, representative synthetic load, physical test
devices/networks, approved English/iTaukei/Fiji Hindi content and accessibility
reviewers.

## Goal

Prove the invite-only Suva pilot is usable, safe and measurable on realistic
Fiji browser/network conditions.

## Acceptance targets

- Search API p95 within two seconds under representative pilot load.
- First visible results within three seconds on a normal Fiji mobile network.
- Twenty-result pages and a 100-result maximum remain enforced.
- Listing updates appear within five minutes or remain visibly stale with alert.
- Keyboard, screen-reader, mobile, desktop, 200% scaling, reduced motion,
  contrast, denial and offline checks pass for every changed journey.
- Translation expansion preserves safety, freshness, price and non-clinical
  meaning; translated legal/safety content has professional review evidence.

## Acceptance

Record device/browser/network, build commit, test data, measurement method,
percentiles, defects, workaround and release decision. No raw search text,
health data or direct identifiers enter performance events.

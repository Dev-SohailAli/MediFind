# Task 20: Exercise incident response and operational privacy controls

## Gate

Requires named founder/security/compliance owners, support escalation contacts,
approved retention/evidence rules and synthetic exercise scenarios.

## Goal

Make critical containment, notification decisions, audit preservation and
post-incident corrective review executable without placing sensitive evidence
in tickets, logs or public status pages.

## Required exercises

Rehearse suspected prescription exposure, privileged MFA compromise, malicious
file, cross-branch authorization failure, kill-switch activation and backup /
restore failure. Record elapsed containment, missed controls, communications
rehearsal, corrective owner/due date and retest evidence.

## Acceptance

Critical exercises automatically block prescription activation when containment
fails. Evidence contains no raw prescription, OTP, password, token, full
contact value or sensitive support free text. Public status copy remains
generic and operationally useful.

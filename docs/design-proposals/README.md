# Design proposal workspace

Claude Design creates reviewable, design-only proposal files in this directory. A proposal is not application code and does not authorise implementation.

Name the initial proposal `initial-mvp-design-proposal.md`. Later proposals use `YYYY-MM-DD-short-scope.md`.

Each proposal includes:

1. Scope, intended roles and non-goals.
2. Design rationale and semantic-token application.
3. Navigation/flow map.
4. Low-fidelity wireframes or structured screen descriptions.
5. Loading, offline, empty, stale, permission, error, forbidden, success, maintenance and security states.
6. Accessibility, localisation and safety review.
7. Open decisions needing founder approval.
8. Statement that no code, services, real data or configuration changed.

Use the [Claude Design agent brief](../claude-design-agent-brief.md) and [initial design-review brief](../initial-claude-design-review-brief.md) as mandatory constraints.

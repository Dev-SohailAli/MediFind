# MediFind

MediFind is a documentation-first plan for a Suva, Fiji pilot that helps buyers find medicines at verified pharmacies.

No application code belongs in this repository until the documentation baseline is approved. Start at [the documentation index](docs/README.md).

## Product boundary

MediFind helps a registered buyer discover a medicine, request prescription review where required, and request a pharmacy-approved collection reservation. It does not diagnose, prescribe, sell, dispense, take payment, or arrange delivery in v1.

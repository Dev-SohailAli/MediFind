# MediFind

MediFind is a web-only plan for a Suva, Fiji pilot that helps buyers find medicines at verified pharmacies.

The current client is a responsive React web application/PWA. Start at [the documentation index](docs/README.md) and [the Cloudflare web architecture](docs/cloudflare-web-architecture.md).

## Product boundary

MediFind helps a registered buyer discover a medicine and, when the protected pilot is approved, request pharmacy-approved collection. It does not diagnose, prescribe, sell, dispense, take payment, arrange delivery, or ship a native app in v1.
